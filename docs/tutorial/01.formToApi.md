# 기능 요구사항: 고객 문의 폼 자동 응답 워크플로

## User Define Prompt

고객 문의를 접수하고 즉시 답변을 보여주는 n8n 워크플로를 설계해줘.

요구 조건은 다음과 같아.

- n8n Form Trigger 노드를 사용해 고객 입력을 받는다.
- 입력 필드는 이름, 이메일, 문의 내용, 날짜, 시간으로 구성한다.
- OpenAI Chat Model 노드에서 문의 내용을 분석해 고객에게 보낼 답변을 생성한다.
- 답변은 정중하고 명확한 한국어로 작성하고, 문의 의도에 맞는 해결 안내를 포함한다.
- Respond to Webhook 노드에서 OpenAI가 생성한 답변을 폼 제출 완료 화면에 즉시 표시한다.
- 사용자는 폼 제출 직후 이메일 회신을 받은 것처럼 답변을 확인할 수 있어야 한다.

추가 지침:

- 필수 노드는 n8n Form Trigger, OpenAI Chat Model, Respond to Webhook 3개를 반드시 포함한다.
- 데이터 매핑은 Form Trigger 입력값이 OpenAI 프롬프트로 정확히 전달되도록 구성한다.
- 최종 응답 화면에는 고객 이름과 생성된 답변 본문이 함께 표시되게 한다.
- 인증 정보가 없으면 placeholder로 두고, 워크플로 구조는 즉시 실행 가능한 형태로 작성한다.
